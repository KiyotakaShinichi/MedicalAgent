# What This Does Not Prove

Passing OncoTrack's tests and release gates does not prove clinical safety or
clinical efficacy.

## It Does Not Prove

- the model predicts real patient treatment response
- the toxicity head detects real clinical toxicity
- the regression score measures true tumor response
- the RAG layer is medically complete
- the agent is safe for unsupervised patient use
- the KB is equivalent to NCCN/ASCO/ESMO professional guidelines
- the genetic module performs genetic counseling
- tumor-marker trends diagnose recurrence
- supplement flags determine whether a product is safe
- the platform is HIPAA-ready or regulated-software-ready

## It Does Prove, When Gates Are Green

- the core integration tests pass
- release artifacts are present and current enough for demo review
- known synthetic-data leakage and shortcut checks are being run
- model outputs are wrapped in evidence sufficiency and claim boundaries
- RAG source governance is checked
- unsafe claim classes are regression-tested
- the project is honest about unresolved gaps

## Correct Portfolio Claim

OncoTrack is a safety-first, synthetic-only healthcare AI engineering prototype
that demonstrates guardrailed RAG, evidence-aware temporal ML, traceability,
source governance, release gates, and clinician-in-the-loop workflow design.

It is not clinical validation.
