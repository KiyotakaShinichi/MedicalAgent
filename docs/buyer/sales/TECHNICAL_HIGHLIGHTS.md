# Technical highlights

- Large modular FastAPI and React/TypeScript research system
- Synthetic longitudinal oncology-monitoring workflows with explicit boundaries
- BM25 + dense retrieval, reciprocal-rank fusion, source tiers, allowed-use
  filtering, citation/claim checks, and traceable evidence envelopes
- Deterministic safety before and after generation; fail-closed failure paths
- Adversarial, metamorphic, multilingual, fault-injection, and agentic evaluations
- Synthetic-only ML/MLE with temporal CV, calibration, leakage/shortcut audits,
  uncertainty/abstention, lineage, promotion gates, and XAI artifacts
- Alembic, SQLite/PostgreSQL shapes, Redis seams, durable automation tasks, n8n
  signing/redaction, and buyer-owned provider boundaries
- Structured redacted logs, request correlation, liveness/readiness, and local
  runtime metrics
- Pinned dependencies, SBOMs, offline/fresh-clone checks, Docker, CI, and extensive
  backend/frontend automated tests
- Honest negative evidence, 757-file protected-evidence manifest, deterministic
  demo and package verification

Every point describes engineering evidence, not clinical validation or a
production healthcare claim.
